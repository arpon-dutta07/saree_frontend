# CG Sarees - Luxury Indian Ethnic Wear

Front-end build featuring layered interactive hero section with framer-motion orchestration.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Layer Stacking Architecture
- Background (z: 0)
- Lanterns & Floral Vine (z: 20)
- Seated Red Model (z: 24)
- Standing Black Model (z: 26)
- Headline & CTA (z: 30)
- Foreground Floral Uruli (z: 40)
- Navbar & Monogram (z: 50)

## Animation Orchestration
Staggered entry timeline using framer-motion with custom cubic-bezier easing.

## Asset Processing
Alpha-channel transparency keying and soft boundary feathering to eliminate crop seams.
